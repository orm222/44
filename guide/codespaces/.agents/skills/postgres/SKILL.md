# 이 하네스의 PostgreSQL 적용

사용자가 선택한 웹 기본 구성은 SvelteKit + FastAPI + PostgreSQL이다. 업무 테이블·제약·트랜잭션은 확인된 요구사항과 승인된 계획으로 정한다. 연결 예제의 notes 테이블은 업무 요구사항이 아니다.

- [실행 예제](../../../starters/web-postgres/README.md)를 필요한 경우 읽는다. PostgreSQL 17, psycopg 3, Python 3.9 조합이며 예제에는 ORM이 없다.
- SQL 값은 바인딩한다. 비밀번호는 소스·이미지에 넣지 않고 Compose secret 파일로 전달한다.
- 초기 SQL은 빈 볼륨에서만 실행된다. 기존 DB 변경에는 데이터 보존·이행·검증 방법을 계획하고 승인받는다.
- 실제 PostgreSQL에서 쓰기·읽기·제약을 검사한다. mock 단위 검사를 실제 DB 통합 검사로 보고하지 않는다. 재시작 뒤 데이터가 남는지도 별도로 확인한다.
- 예제의 app_local은 로컬 개발용 초기 DB 관리자다. 외부 서비스로 배포할 때는 앱 전용 최소 권한 역할과 인증 요구사항을 따로 정한다.
- 일반 종료는 볼륨을 보존한다. 데이터 삭제·기존 볼륨의 메이저 업그레이드를 암묵적으로 수행하지 않는다.

계획·구현·독립 검토·단계별 승인은 기존 run_harness.py 흐름을 따른다. 구현자는 JSON 변경안을 반환하고 Python이 허용된 파일에 적용한다. 이 스킬은 승인이나 160분 마감, 중단 복구를 우회하는 실행기능을 추가하지 않는다.
